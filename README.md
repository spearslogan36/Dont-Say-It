# Don't Say It

A Windows 95-style desktop companion that listens to your voice. Use it to run voice commands in games, or ban words and get punished every time you say one.

**Status:** early development. Nothing to download yet.

## Planned features
- A CRT-monitor companion that sits on your desktop and reacts to everything
- **Voice Command Mode:** turn spoken phrases into key presses, macros and scripts
- **Punishment Mode:** banned words trigger a wheel of punishments, popup spam and more
- OBS and Twitch support for streamers
